# Deep Learning Term Project – Automated Wildlife Classification

This directory contains artifacts from the team-based term project
completed as part of **SCS 3546 – Deep Learning** at the
University of Toronto School of Continuing Studies.

## Project Overview
The project investigates automated wildlife classification using
camera trap images from Taï National Park. Multiple deep learning
models were explored using transfer learning, including:

- VGG16
- ResNet50
- EfficientNetV2S

## Team Collaboration
This was a team project completed with two other classmates.
The final results, comparisons, and conclusions are documented
in the slide deck located in the `slides/` directory.

## My Contribution
My primary responsibility in this project was:

- Designing, training, and evaluating the **VGG16-based model**
- Performing multiple fine-tuning experiments
- Analyzing validation and test performance
- Contributing VGG16-related findings to the final presentation

Only the code that I personally authored is included in this repository.
