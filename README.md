# UofT Deep Learning Assignments (Course #3546)

This repository contains my own work completed as part of **Course #3546 – Deep Learning** at the **University of Toronto School of Continuing Studies**, within the **Artificial Intelligence Certificate Program**.

The course extends classical machine learning concepts to modern deep neural networks, combining theory with hands-on implementation using **TensorFlow 2 / Keras**, primarily developed in **Google Colab**.

---

## 🧠 Topics Covered

Across assignments and the term project, this repository covers:

- Fundamentals of deep learning using Keras
- Convolutional Neural Networks (CNNs) for image classification
- Transfer learning with pre-trained architectures
- Recurrent and transformer-based models for text
- Contextualized word embeddings for NLP tasks
- Generative models (e.g., Variational Autoencoders, GANs)
- End-to-end deep learning project design and evaluation

---

## 🧪 Assignments Overview

### Assignment 1 — Deep Learning with Keras
Introduction to building, training, and evaluating deep neural networks using TensorFlow/Keras, including architecture design and basic hyperparameter tuning.

### Assignment 2 — Convolutional Neural Networks & Transfer Learning
Implementation of CNNs for computer vision tasks, including feature extraction and fine-tuning of pre-trained models.

### Assignment 3 — Contextualized Word Embeddings
Exploration of modern NLP techniques using deep models for text representation and semantic understanding.

### Assignment 4 — Generative Models
Design and training of deep generative models to synthesize new data samples, with analysis of learned latent representations.

---

## 🏁 Term Project

The term project applies deep learning architectures to a non-trivial real-world problem, emphasizing:
- Model selection and architecture design
- Training stability and evaluation
- Interpretation of results
- Clear communication of technical decisions

The project was completed **as part of a small team**.  
Only **my individual contribution (VGG16-based model and analysis)** is included as executable code in this repository, while the final team presentation is provided for context.
